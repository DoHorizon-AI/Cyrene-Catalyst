# Glossary / 术语表

| English | 中文 | Meaning / 含义 |
|---|---|---|
| Catalyst | Catalyst 数据处理服务 | Cyrene product for ingestion and dataset lifecycle / Cyrene 的数据摄取与数据集生命周期产品 |
| Dataset | 数据集 | Logical collection of related dataset versions / 相关数据集版本的逻辑集合 |
| DatasetVersion | 数据集版本 | Immutable snapshot identified by an artifact digest / 由制品摘要标识的不可变快照 |
| DatasetSpec | 数据集规格 | Declarative recipe for inputs, transforms, and thresholds / 描述输入、变换与门槛的声明式配方 |
| DataPipeline | 数据流水线 | Directed sequence or DAG of processing steps / 处理步骤组成的有向序列或 DAG |
| Lineage | 数据血缘 | Provenance connecting sources, transforms, and outputs / 连接数据源、变换与输出的来源关系 |
| Artifact Plane | 制品平面 | Platform storage boundary for immutable artifacts / 平台存放不可变制品的边界 |
| Capability seam | 能力接缝 | Versioned interface used to consume an external capability / 消费外部能力的带版本接口 |
| Provider | 能力提供方 | Component implementing a declared capability / 实现已声明能力的组件 |
| Contract candidate | 契约候选 | Documented interface awaiting runtime implementation or finalization / 已文档化但等待实现或最终定稿的接口 |
| Compatibility shim | 兼容垫片 | Preserved surface retained for historical compatibility / 为历史兼容而保留的表面 |
| CAS | 内容寻址存储 | Storage addressed by content digest / 通过内容摘要寻址的存储 |
| PII scrubbing | PII 清除 | Removal or masking of personally identifiable information / 删除或掩码个人可识别信息 |
| MinHash deduplication | MinHash 去重 | Approximate similarity method for duplicate detection / 用于重复检测的近似相似度方法 |
